# Engineering Constitution

## Purpose
This document defines the organization-wide, non-negotiable engineering principles.

## Principles
1. Reuse before create.
2. Simplicity before over-architecture.
3. Explicit structure and explicit contracts.
4. Documentation synchronized with implementation.
5. Responsive and accessible web interfaces.
6. Performance as a built-in concern.
7. User-facing help translated; technical docs kept in English.
8. Repository files are the source of truth over volatile memory.
