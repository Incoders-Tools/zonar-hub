# Angular Org Template

A GitHub template repository for starting new Angular applications with your organization's AI agent contract, repository-wide Copilot instructions, agent skills, and a scalable standalone Angular structure.

## Suggested repository description

GitHub template for Angular applications with organization standards, Copilot agent contract, responsive architecture, themes, and language support.

## What this template includes

- Angular standalone application structure
- feature-first folder organization
- repository-wide GitHub Copilot instructions
- specialized agents and skills for documentation, translation, responsiveness, performance, and audit
- technical documentation and registry structure
- theme-ready and language-ready application setup
- HTTP interceptor placeholders for loading, language, and error handling
- shared and feature separation designed for scale

## Template repository guidance

Once this repository exists on GitHub:
1. Open the repository.
2. Go to **Settings**.
3. In the repository settings, enable **Template repository**.
4. Save changes.

After that, GitHub will show **Use this template** on the repository page.
